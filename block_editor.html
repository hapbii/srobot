⬛ SCARA BLOCK EDITOR — 조작 가이드

── 블록 추가

드래그왼쪽 팔레트에서 블록을 프로그램 영역으로 드래그해 추가
WP ＋오른쪽 웨이포인트 목록에서 ＋를 클릭하면 MoveL 블록으로 자동 추가

── 블록 편집

드래그 재정렬블록을 드래그해 순서 변경
✕블록 오른쪽 ✕ 버튼으로 삭제
파라미터 입력각 블록의 수치 직접 입력 (X, Z, 각도, 속도 등)

── 블록 종류

🎯 MoveL직선 이동 — X·Z 좌표 지정. 웨이포인트 ＋로 자동 채움
🔗 MoveJ관절 이동 — J1·J2 각도 직접 지정
🏠 Home홈 위치로 복귀
✊ Gripper그리퍼 열기 / 닫기
⏱ Wait지연 시간 (초 단위)
🔁 LoopN회 반복 — Loop 블록 이후 블록들이 반복 실행
❓ If조건 분기 — 변수 값 비교, 거짓이면 다음 블록 건너뜀
📝 SetVar변수 값 설정
🛑 Stop프로그램 즉시 종료

── 웨이포인트 활용

메인창 우클릭3D 뷰에서 우클릭 → 웨이포인트 저장 → 에디터에 자동 동기화
WP 목록 ＋저장된 웨이포인트 클릭 시 해당 좌표의 MoveL 블록 자동 생성

── 실행 / 저장

▶ 실행프로그램 순차 실행 — 메인 창의 로봇이 실제로 움직임
■ 정지실행 중단
⬇ 내보내기현재 프로그램을 JSON 파일로 저장

── 단축키

I이 가이드 열기 / 닫기
ESC이 가이드 닫기
💡 메인 창을 열어둔 상태에서 실행하면 3D 뷰의 로봇이 블록 순서대로 움직입니다.
